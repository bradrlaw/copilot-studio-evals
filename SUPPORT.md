# Support

## How to file issues and get help

This project is supported by its maintainers and community on a best-effort basis.
It does not include Microsoft Customer Service & Support (CSS) support or a
guaranteed response or resolution time.

Use GitHub Issues to report reproducible bugs or request features. Before opening
an issue:

1. Search existing issues to avoid duplicates.
2. Review the project documentation and included examples.
3. Remove credentials, personal data, production conversations, tenant and
   environment identifiers, and other confidential information.
4. Include the Python version, operating system, relevant command, expected
   behavior, actual behavior, and a minimal synthetic reproduction where possible.

If GitHub Discussions are enabled, use them for usage questions and general
discussion. Issues that are support requests rather than actionable bugs or feature
requests may be redirected or closed.

Questions about Microsoft Copilot Studio, Azure, Power Platform, or another
Microsoft product should use that product's official documentation and support
channels.

## Microsoft Support Policy

Support for this project is limited to the community and maintainer resources
listed above. This project is not covered by a Microsoft support contract merely
because it is hosted in a Microsoft GitHub organization or maintained by Microsoft
employees.

Do not report security vulnerabilities through public issues. Follow
[SECURITY.md](SECURITY.md) for Microsoft's security reporting process.
